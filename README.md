This repository contains a parallel corpus that contains regular expressions for various roman urdu words and natural language descriptions that describe the regex. 
It is useful for automatic regex synthesis for unseen words. The regex are added by using phonetic variants of words.
reg-gen with attention is a pynotebook that contains code for basic LSTm based sequence to sequence model which take NL descriptions as input to generate regex as output
sentiment classifier and bert classifier pynotebook contains code for LSTM and mBERt for sentiment classificaiton of ROman urdu comments sentiemnt datasets after normalization apply normalization via regex for few common words
dictionaries and reg-gen lexcion contain the parallel corpus 
spell corrector contains code for normalizaiton process of raw dataset via regex patterns
two articles published from this research work containing details of automatic regex synthesis methods for english and structure and design of multimodal dataset for roman urdu regex
